# IELTS Writing Translation

Complete sentence-by-sentence Chinese-to-English IELTS writing practice course.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run test:data
npm run build
```

The course contains all 30 model essays and 538 source sentences from `雅思写作范文.docx`, preserving the original six-topic, five-task-type order. A complete Contents page presents the 30 prompts as the same 6 × 5 course map used in the Feishu `大作文30篇` sheet. A persistent Contents control is available from every course screen, and Back on the first practice sentence also returns to the course map. Progress is stored locally on each device.
